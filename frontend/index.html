    Guard approves code, not IDs

    An extension keeps its ID when a new version ships, so a hijacked update passes any allowlist. Guard pins every approved extension to the build that was reviewed. Harmless updates are approved on their own; anything that gains access is quarantined. Approved software is blocked the moment an advisory hits its version, and released when the fix is installed.

      Add a computer

      The agent reads the browser extensions and installed programs on a computer, analyses them there, and sends the results here. It needs Python 3.10 or newer and nothing else.

      1. Check the address teammates will use

        Other computers must reach this server over the network, so localhost only works on this computer.

      2. Download the agent

        The address is already written inside the start files.

        Download blindspot-agent.zip

      3. On each computer: unzip and double-click

        run_agent.bat reports once. watch_agent.bat keeps watching and reports every 10 minutes. On Mac or Linux: sh run_agent.sh.

        Run from a terminal

        In the blindspot folder, run:

        terminal

      4. Watch it arrive

        This page checks for new reports every 10 seconds.
